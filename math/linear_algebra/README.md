# Linear Algebra

This project introduces the basic matrix and vector operations used in machine learning.

## Main Concepts

| Concept | What it means | Why it matters |
|---|---|---|
| Vector | A one-dimensional list of numbers | Represents data such as features, scores, or coordinates |
| Matrix | A two-dimensional table of numbers | Stores datasets, images, transformations, or model parameters |
| Shape | The number of rows and columns | Helps check if operations like matrix multiplication are valid |
| Transpose | Flipping rows into columns | Useful for aligning data before calculations |
| Slicing | Selecting part of a vector or matrix | Helps extract specific rows, columns, or values |
| Element-wise operations | Applying an operation to matching elements | Useful for adding, subtracting, or scaling data |
| Concatenation | Joining vectors or matrices | Combines data together |
| Dot product | Multiplying matching values and summing them | Measures similarity or weighted scores |
| Matrix multiplication | Combining rows and columns | Used in transformations, neural networks, and linear models |
| NumPy | Python library for numerical computing | Makes matrix operations faster and easier |

## Why This Project Matters

Linear algebra is one of the foundations of machine learning.  
Data is often represented as vectors and matrices, and many ML algorithms depend on matrix operations.
