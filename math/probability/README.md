# Probability

This project covers probability rules, descriptive statistics, and common probability distributions.

## Main Concepts

| Concept | What it means | Why it matters |
|---|---|---|
| Probability | Measure of how likely an event is | Helps reason under uncertainty |
| Union | Event A or event B happens | Used for OR questions |
| Intersection | Event A and event B happen together | Used for AND questions |
| Independence | One event does not affect another | Allows multiplication of probabilities |
| Disjoint events | Events that cannot happen at the same time | Simplifies OR probability |
| Distribution | Shows how probability is spread over outcomes | Describes random variables |
| Mean | Average value | Shows the center of data |
| Variance | Average squared spread from the mean | Measures spread |
| Standard deviation | Typical distance from the mean | Easier-to-understand spread |
| Percentile | Relative position in a dataset | Shows ranking compared to others |

## Common Distributions

| Distribution | Use case |
|---|---|
| Poisson | Number of events in time or space |
| Exponential | Waiting time until next event |
| Normal | Bell-shaped continuous data |
| Binomial | Number of successes in fixed trials |

Probability helps machine learning models handle uncertainty and make predictions.
