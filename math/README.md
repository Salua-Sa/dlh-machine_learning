# Math

Foundational mathematics for machine learning — linear algebra, calculus, probability, Bayesian probability, and visualization.

## Modules

| Module | Description |
|---|---|
| [Linear Algebra](./linear_algebra) | Matrix operations: slicing, shape, transpose, element-wise operations, concatenation, dot product, matrix multiplication, NumPy basics |
| [Advanced Linear Algebra](./advanced_linear_algebra) | Determinant, minors, cofactors, adjugate, inverse matrix, eigenvalues, eigenvectors, and definiteness |
| [Calculus](./calculus) | Summation, derivatives, partial derivatives, integrals, definite and indefinite integrals, double integrals |
| [Bayesian Probability](./bayesian_prob) | Prior probability, likelihood, marginal probability, posterior probability, Bayes’ theorem |
| [Multivariate Probability](./multivariate_prob) | Joint probability, marginal probability, conditional probability, independence, multivariate distributions |
| [Probability](./probability) | Basic probability rules, distributions, mean, variance, standard deviation, percentiles, binomial, normal, Poisson, exponential |
| [Plotting](./plotting) | Data visualization with Matplotlib: line plots, scatter plots, bar charts, histograms, labels, scaling, multiple plots |

## Learning Path

1. **Linear Algebra**  
   Learn vectors, matrices, shapes, slicing, transposes, and basic matrix operations.

2. **Advanced Linear Algebra**  
   Understand determinant, inverse, minors, cofactors, eigenvalues, eigenvectors, and matrix definiteness.

3. **Calculus**  
   Study derivatives, integrals, and how rates of change are used in machine learning.

4. **Plotting**  
   Visualize data using Matplotlib and understand how graphs help explain patterns.

5. **Probability**  
   Learn probability rules, distributions, expected value, variance, standard deviation, and percentiles.

6. **Bayesian Probability**  
   Understand how probabilities are updated when new evidence is available.

7. **Multivariate Probability**  
   Study probability involving multiple variables and relationships between events.


## Why This Matters for Machine Learning

Math is the foundation of machine learning.  
Linear algebra helps represent data, calculus helps optimize models, probability helps handle uncertainty, and plotting helps understand data visually.
