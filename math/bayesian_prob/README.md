# Bayesian Probability

This project explains how to update probabilities when new evidence becomes available.

## Main Concepts

| Concept | What it means | Why it matters |
|---|---|---|
| Prior probability | Probability before seeing new evidence | Represents the original belief |
| Likelihood | Probability of the evidence if the hypothesis is true | Measures how well the evidence supports the hypothesis |
| Marginal probability | Total probability of the evidence | Used as the denominator in Bayes' rule |
| Posterior probability | Updated probability after seeing evidence | Final updated belief |
| Bayes' theorem | Formula for updating probability using evidence | Used in diagnosis, spam filters, and decision-making |

## Bayes' Rule

```text
P(A | B) = P(B | A) * P(A) / P(B)
---
